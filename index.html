How the compression works

CPB first shrinks and re-compresses the pictures inside your PDF and keeps your text as real text. It picks the best quality that still fits the size you chose.

If that is not enough to reach a very small size such as 100 KB, and you have allowed it, CPB saves each page as a compressed image and rebuilds the PDF. The file gets much smaller, but the text can no longer be selected.

Very long documents and high-resolution scans may not fit under a tiny size. In that case the tool tells you the smallest size it could reach, so you can pick a larger target.

Questions people ask

Is my PDF stored on your server?

No. Your file is sent over an encrypted connection, compressed, and removed from our server as soon as the result is ready.

Can it compress a PDF to 100KB?

Yes in most cases. CPB aims for the size you pick and gets under it whenever the file can be made that small. Very long documents may not fit, and the tool will show the smallest size it reached.

Will the text still look sharp?

Text stays sharp when it can be kept as text. Pictures lose some detail at small sizes. Larger targets such as 300 or 500 KB keep pictures clearer.

Can I select the text after compressing?

Usually yes. Only if you allow it, and the size cannot be reached any other way, pages are saved as images and text is no longer selectable.

Do I need an account?

No sign-up and no watermark. Open the page and start.

Is there a file size limit?

Yes. To keep the service fast for everyone, very large files and very long documents are not accepted. The tool tells you if a file is over the limit.

Can it open password-protected PDFs?

No. Remove the password first, then compress the file.
