How the compression works

To reach small sizes such as 100 KB, CPB turns each page into a compressed image and rebuilds the PDF from those images. It picks the best quality that still fits your size, page by page.

Because of this, text in the new file can no longer be selected or searched. If you need to keep selectable text, use the original file for that purpose and the compressed copy for uploading.

Long documents and high-resolution scans may not fit under a very small size. In that case the tool tells you the smallest size it could reach, so you can pick a larger target.

Questions people ask

Is my PDF uploaded to a server?

No. Compression runs inside your browser, so your file stays on your device.

Can it compress a PDF to exactly 100KB?

It aims for the size you pick and gets under it whenever the file can be made that small. Very long documents may not fit under 100 KB, and the tool will show the smallest size it reached.

Will the text still look sharp?

Larger targets such as 300 or 500 KB keep text clearer. Smaller targets trade some sharpness for size.

Can I select the text after compressing?

No. Each page is saved as an image to reach small sizes, so text is no longer selectable.

Do I need an account?

No sign-up and no watermark. Open the page and start.

Can it open password-protected PDFs?

No. Remove the password first, then compress the file.
